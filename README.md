## kms thing by TouchTrigger
**kms thing** - это простой и легкий бесплатный активатор активатор для Windows 10-11, написаный на Python.
### Как использовать
**Активация:**
- Введите ключ и сервер "из репозитория, свои или из файлов key.txt и server.txt"
- Ждите :)
  
**Снятие активации:**
- Выберите вариант с удалением ключей 
- Если не работает, выберите вариант без удаления ключей
